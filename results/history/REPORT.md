# Historical results, recomputed

Generated by `experiments/reanalyze_history.py` from the per-pair scores each version saved. Every AUC uses the same estimator (Mann-Whitney), a stratified bootstrap (5000 resamples) and a one-sided permutation test (5000 shuffles), seed 0.

**v2 (MVP) is not in this table.** Its submission claimed precision 87.3%, recall 82.1% and AUC-ROC 0.91 on an 'SMP test set', but no per-pair scores, predictions or run logs for that evaluation exist, and the pair files in that folder hold 16 positives and 16 negatives. The claim cannot be reproduced, so it is not used anywhere in this repository.

## v4 — multi-chunk CNN + interpretable features (training run)

* Split sizes 63/13/14 pairs; recordings shared train∩val = 0, train∩test = 0 — the split is track-disjoint, so there is no recording-level leakage.
* Best validation loss 0.674 (epoch 13); a constant predictor at the validation prevalence scores 0.690.
* Training loss fell 0.687 → 0.619 while validation loss rose to 0.762: memorisation, not learning.
* Validation accuracy never exceeded 50.0% (majority class: 53.8%).
* No test-set evaluation was logged for this run, so there is no v4 test number.
