# Real pairs: rebuilt features vs the v3 CNN

Generated by `experiments/real_pairs.py` (221 s). The 27 pairs the CNN was evaluated on as 'unseen tracks': 11 derived (6 plagiarism cases, 5 remakes) and 16 unrelated pairings, curated 9-53 s excerpts. The features were not tuned on these pairs. CNN scores are the ones v3 saved.

With 11 positives the interval half-width is about ±0.2: a feature needs an AUC near 0.75 before its lower bound clears 0.5. Read differences between rows as directions, not rankings. Five rebuilt features were tested: with a Bonferroni correction the significance level is 0.010, so no single p-value here is significant on its own. What the table supports: the order-aware harmonic features (`chroma_dtw`, `markov_js`) point the right way on unseen real pairs where the CNN did not, and the effect needs a larger pair set to be confirmed.
